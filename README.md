# Student Performance Predictor

This is a beginner machine learning project.

The goal of this project is to predict whether a student may pass or need improvement based on some basic student information.

## Input

The model uses:

- Study hours
- Attendance
- Assignments completed
- Previous exam score

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

## Machine Learning Model

I used a Decision Tree Classifier for this project.

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py
